# CGPA Calculator Web App

This project is a small CGPA calculator web app with a clean folder structure.

## Files

- `index.html` — main application shell and layout.
- `css/styles.css` — all styling for the app.
- `js/app.js` — logic for adding rows, calculating CGPA, and saving state.

## Usage

Open `index.html` in a browser to use the app.

## Features

- Add and remove course rows
- Support for Core, COD, and Fundamental course sections
- Computes current CGPA and projected CGPA
- Persists data in browser storage
- Reset/purge all saved information
